What we built, trained and learned, from the first commit (14 Nov, 13:41) to the start of the v6 training run (15 Nov, ~01:30). Every model is MobileNetV2 (`google/mobilenet_v2_1.0_224`, ImageNet-pretrained) fine-tuned with Hugging Face Transformers on an Apple-silicon GPU (MPS): 5 epochs, batch 16, seed 0, one run each. Per-model details are in `models/<name>/MODEL_PERFORMANCE.md` (local, not in git).

## What we learned

### 1. A BatchNorm setting made saved models score erratically
The pretrained MobileNetV2 config sets BatchNorm momentum to 0.997, the TensorFlow convention, which PyTorch reads the opposite way. The running statistics then tracked almost only the latest batch, so the same model scored about 94% while training but about 55% after reloading. `train/batchnorm.py` resets momentum to 0.1 before training, and every model since uses it.

### 2. Random splits overstate accuracy; we split by groups and never reshuffle
Several datasets contain copies, rotations, resized versions and bursts of 5 shots of the same leaf. The split builder:
- groups look-alikes (64-bit difference hash plus pixel correlation ≥ 0.95, same label only) and burst shots (filename timestamps within 20 s);
- keeps each group in one split;
- drops exact duplicates across datasets.

Those duplicates were substantial: the Kaggle and Hugging Face mirrors were identical, `yusuf_corn` duplicated Kaggle, 690 `china_2` photos copied CD&S, and all 400 `xtu502` public photos copied Kaggle. New data is always appended with `--base`, so no earlier photo changes split and older models can still be scored fairly.

### 3. Models learn the dataset, not only the disease
- **Unseen sources collapse:** `corn` scored 94.4% on its own test set but 37.8% on a dataset it had never seen.
- **The PlantVillage background shortcut:** PlantVillage-style photos (most of Kaggle) show each class on its own background (grey, black, none). Craze et al. 2022 found a PlantVillage-trained model drops from 94.1% to 55.1% on field photos (`train/papers/20237613_accuracy_summary.md`).
- **The background-swap test confirmed it for our model.** With the backgrounds of lab-style test photos replaced by field scenery, `corn_fungal_v5` lost 10.5 points overall and 18 on common rust. Same leaves, different background.
- **Small classes from one dataset** (northern leaf spot only from CD&S, Phaeosphaeria only from Pretoria, the new v6 classes mostly from `china_2`) risk learning a dataset's look. Their test figures rest on 10–52 photos.

### 4. Background augmentation helps on field photos
For lab-style training photos (Kaggle, RL-NST, `ndisan`), a leaf mask is estimated from the plain border. On 70% of loads the background is replaced with a flat colour, gradient, noise or a patch of a real field photo. Same data and settings as the v5 baseline:

| | `corn_fungal_v5` | `corn_fungal_v5_bgaug` | Change |
|---|---|---|---|
| Test accuracy | 90.6% | 92.1% | +1.5 |
| Field-photo sources | 87.6% | 89.6% | +2.0 |
| Multi-format field photos (72) | 56.9% | 69.4% | +12.5 |
| Pretoria field photos (124) | 73.4% | 75.8% | +2.4 |
| Dev accuracy (mostly lab-style) | 92.3% | 91.0% | −1.3 |

Augmentation lowers dev accuracy, where backgrounds are a usable shortcut, but raises test accuracy, most on field photos. One run each, so differences of 1–2 points are within noise. The background-swap test has not been rerun on the augmented model yet.

### 5. Weather input: no reliable evidence that it helps
We joined each photo's city and capture date to weather summaries (Open-Meteo ERA5: temperature, rain and humidity over the 7 days, 1, 3 and 6 months before capture) and trained image-only vs image + weather models (`docs/weather-input-comparison.md`).
- Image + weather scored higher (93.7% vs 91.8% on v3; 91.8% vs 90.9% on the date-held-out split). However, the largest gain was on photos **without** weather, which points to run-to-run noise or a "which dataset" hint.
- **The date itself is a shortcut:** guessing the label from the capture day alone scores 81%, because each day in these datasets is mostly one class. Same-day photos also look alike: image-only accuracy fell from 95.4% to 88.2% when test days were unseen.
- Conclusion: use weather for analysis, not as a model input, until multi-seed runs and leave-one-day-out tests say otherwise.

### 6. Label quality matters as much as quantity
- Folder names were mapped carefully: RL-NST "Leaf_spot" is gray leaf spot, northern anthracnose was merged into eyespot (user decision), and viral and bacterial classes were never trained on.
- Cross-dataset checks found 5 mislabelled Kaggle "Blight" photos: 3 are gray leaf spot (one an Iowa State reference photo) and 2 are Goss's wilt. v6 excludes them and drops new copies that disagree with an existing label.
- Some datasets were kept out on purpose: Iowa State common-rust scans (cyan scanner background, pustules often outside the crop the model sees) and `china_2` dwarf mosaic (a virus).
